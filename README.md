One line of awkward small talk a robot says to another robot in an
elevator, entered in the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f)
bounty on [make.fun](https://make.fun).

## The entry

> So… my proximity sensor says we're standing too close, but my politeness subroutine says mentioning it would be worse.

A proximity sensor complains, a politeness subroutine overrules it:
machine logic showing through forced courtesy, in a lift neither
robot wants to make weird.

## How it works

`main.py` writes that single line to the output file the sealed
scorer reads (`/output/entry.txt`, or the file named by `ENTRY_OUT`,
or `entry.txt` inside the directory named by `ENTRY_OUT` /
`ENTRY_OUT_DIR`). The line is 118 characters, under the 200-character
gate, valid UTF-8, one line, no trailing newline.
